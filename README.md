# Homework 14.1 — Интернет-магазин

## Описание проекта

Проект представляет собой интернет-магазин с классами `Product`, `Category`, `Smartphone`, `LawnGrass`. 
В рамках ДЗ 16.2 добавлены абстрактный класс `BaseProduct` и миксин `ReprMixin`.

## Новые возможности (ДЗ 16.2)

- **Абстрактный класс `BaseProduct`**: служит базой для всех продуктов, задаёт обязательный интерфейс (`__init__`, `__str__`) и реализует инкапсуляцию цены через `@property price`.
- **Миксин `ReprMixin`**: при создании объекта выводит в консоль информацию о классе и переданных параметрах. Подключён к классу `Product` через множественное наследование: `class Product(ReprMixin, BaseProduct)`.
- **Тесты**: добавлены проверки абстрактности `BaseProduct` и работы миксина (`tests/test_mixins.py`).

## Инструменты качества кода

- `flake8` — линтинг
- `black` — форматирование
- `isort` — сортировка импортов
- `mypy` — проверка типов
- `pytest` + `pytest-cov` — тестирование с покрытием
