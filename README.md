# Интернет-магазин (курсовая работа)

Учебный проект интернет-магазина: классы товаров и категорий,
наследование, загрузка из JSON, магические методы, тесты.

## Реализованный функционал

- Классы `Product` и `Category` с атрибутами.
- Атрибуты класса `category_count` и `product_count` для подсчёта
  категорий и товаров.
- Приватные атрибуты `__price` и `__products` с геттерами/сеттерами.
- Класс-метод `Product.new_product()` для создания товара из словаря.
- Метод `Category.add_product()` для добавления товаров в категорию.
- Классы-наследники от `Product`:
  - `Smartphone` — с атрибутами `efficiency`, `model`, `memory`, `color`.
  - `LawnGrass` — с атрибутами `country`, `germination_period`, `color`.
- Магические методы:
  - `__str__` для `Product` и `Category`.
  - `__add__` для `Product`: складывает стоимость товаров
    (цена × количество), но только для объектов **одного класса**
    (проверка через `type()`). При разных классах — `TypeError`.
- Защита `Category.add_product`: принимает только объекты `Product`
  и его наследников (проверка через `isinstance`). Иначе — `TypeError`.
- Загрузка данных из JSON-файла (`loaders.py`).
- Тесты (`pytest`) — 37 тестов, покрытие `src/` — 100%.
