# Интернет-магазин (курсовая работа)

## Реализованный функционал

- Классы `Product` и `Category` с атрибутами.
- Атрибуты класса `category_count` и `product_count` для подсчёта категорий и товаров.
- Загрузка данных из JSON-файла (`loaders.py`).
- Тесты (`pytest`) с покрытием 100%.

## Инструменты качества кода

- `flake8` — линтинг
- `black` — форматирование
- `isort` — сортировка импортов
- `mypy` — проверка типов
- `pytest` + `pytest-cov` — тестирование с покрытием

## Запуск

```bash
# Установка зависимостей
poetry install

# Запуск приложения
python src/main.py

# Запуск тестов
pytest --cov=src tests/
