# Интернет-магазин (курсовая работа)
Реализованы базовые классы Category и Product

## Реализованный функционал

- Классы `Product` и `Category` с атрибутами.
- Атрибуты класса `category_count` и `product_count` для подсчёта категорий и товаров.
- Загрузка данных из JSON-файла (`loaders.py`).
- Тесты (`pytest`) с покрытием 100%.
